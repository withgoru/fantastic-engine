# Google Apps Script 연동

`Code.gs`는 [#9](https://github.com/withgoru/fantastic-engine/issues/9)에서 연동한 Google Apps Script
Web App의 소스입니다. Apps Script 자체는 이 저장소에서 자동 배포되지 않으므로, 코드를 바꿨다면
**직접 Apps Script 편집기에 다시 붙여넣고 재배포**해야 실제 스프레드시트에 반영됩니다.

## 배포 방법

1. 대상 스프레드시트 → 확장 프로그램 → Apps Script
2. `Code.gs` 내용을 이 파일 내용으로 교체
3. 저장
4. 배포 → **배포 관리** → 연필 아이콘(수정) → 버전: **새 버전** → 배포
   - "새 배포"를 누르면 URL이 바뀌어 프론트엔드(`VITE_GAS_WEB_APP_URL`)를 다시 맞춰야 하니
     기존 배포를 "새 버전"으로 수정하는 방법을 사용할 것

## 이 버전에서 바뀐 점 (#24 보안 점검)

사용자가 품목/수량/현재출하채널/연락처 같은 자유입력 필드에 `=`, `+`, `-`, `@`로 시작하는 값을
입력하면, 구글 시트가 이를 수식으로 해석해 실행할 수 있는 스프레드시트 수식 인젝션(CSV
Injection) 위험이 있었습니다. `sanitizeForSheet()`로 해당 문자로 시작하는 문자열 앞에
작은따옴표를 붙여 항상 일반 텍스트로 저장하도록 수정했습니다.
